# BMIN5030 Final Project

This repository contains all of the files created for my final project!

Using the Aggregate Analysis of ClinicalTrials.gov (AACT), a public database of all registered clinical studies, for this project I am building an NLP extraction pipeline to characterize how anti-AAV antibody eligibility criteria vary across AAV gene therapy trials, and which trial characteristics (serotype, sponsor, indication, year) are associated with that variation. At this point in time, I've completed the regex pipeline as a baseline, and I will finish the LLM-based NLP pipeline to benchmark against this baseline. We will further evaluate semantic disambiguation of antibody relevance, rule direction/polarity, assay type, and normalized titer thresholds.

1. aact_data_dictionary_2026-11-05.csv is the data dictionary for the AACT database.
1. final_project_template.qmd (to be renamed later) contains all the code and writing for the final report.
1. .gitignore contains a few lines outlining the data files in my personal working directory that should be ignored in my git updates
